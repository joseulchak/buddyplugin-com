Instalação

O Buddy Editor é distribuído em um único arquivo, BuddyEditor-4.0.1.zxp, instalado com o ZXP Installer da aescripts.

Passo a passo

  1. Instale o ZXP Installer. Baixe-o no site da aescripts e instale normalmente. Só é preciso fazer isso uma vez.
  2. Baixe o Buddy Editor. Na página de download, baixe o arquivo BuddyEditor-4.0.1.zxp.
  3. Feche o Premiere Pro.
  4. Abra o ZXP Installer e arraste o arquivo .zxp para dentro dele. Aguarde a mensagem de instalação concluída.
  5. Abra o Premiere e vá em Janela > Extensões > Buddy Editor (em inglês: Window > Extensions > Buddy Editor).

Baixou o arquivo certo?

Na página de download do GitHub, baixe o arquivo BuddyEditor-4.0.1.zxp. Os arquivos "Source code (zip)" e "Source code (tar.gz)" são o código-fonte e não instalam o plugin.

O que acontece na primeira abertura

  • O Buddy instala o FFmpeg em %LOCALAPPDATA%\BuddyEditor\bin e cria as pastas de dados em %LOCALAPPDATA%\BuddyEditor.
  • O painel pode mostrar "Aguardando o Premiere responder…" enquanto o projeto termina de abrir. Isso pode levar até um minuto.
  • Em seguida aparece a tela Ative o Buddy Editor. Veja Ativação e licença. A aba Silêncios funciona sem ativação.

Painel não aparece no menu?

Confira se o Premiere estava fechado durante a instalação e instale de novo pelo ZXP Installer. Se continuar, reinicie o computador.
