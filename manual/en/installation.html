Installation

Buddy Editor ships as a single file, BuddyEditor-4.0.1.zxp, installed with the aescripts ZXP Installer.

Step by step

  1. Install the ZXP Installer. Download it from the aescripts website and install it. You only do this once.
  2. Download Buddy Editor. On the download page, get the BuddyEditor-4.0.1.zxp file.
  3. Close Premiere Pro.
  4. Open the ZXP Installer and drag the .zxp file into it. Wait for the installation complete message.
  5. Open Premiere and go to Window > Extensions > Buddy Editor.

Did you download the right file?

On the GitHub download page, get BuddyEditor-4.0.1.zxp. "Source code (zip)" and "Source code (tar.gz)" are the source code and do not install the plugin.

What happens on first launch

  • Buddy installs FFmpeg in %LOCALAPPDATA%\BuddyEditor\bin and creates its data folders in %LOCALAPPDATA%\BuddyEditor.
  • The panel may show "Waiting for Premiere to respond…" while the project finishes opening. This can take up to a minute.
  • Then the Activate Buddy Editor screen appears. See Activation and license. The Silences tab works without activation.

Panel missing from the menu?

Make sure Premiere was closed during installation and install again with the ZXP Installer. If it persists, restart the computer.
