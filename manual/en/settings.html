Settings and diagnostics

The gear at the top of the panel opens Settings.

Sections

Section What it is for
Language Automatic (follows Premiere), Português or English.
Local binaries Shows where FFmpeg is and lets you choose another ffmpeg.exe with Browse. Usually not needed.
Runtime Premiere version, detected graphics card, data and logs folders, with the Open in Explorer button.
License Status, plan, key, expiry, Check now and Deactivate this computer.
Updates Installed version and Check for updates.
Diagnostics Technical tests (use them only when support asks) and Send diagnostics.

Send diagnostics

If something goes wrong, send diagnostics to support:

  1. Click Send diagnostics on the error banner or in Settings > Diagnostics.
  2. Describe what happened. If you want, click See what will be sent.
  3. Click Send. Buddy shows a code such as BR-7F3K9Q: give that code to support.

What is sent

Nothing is sent until you click. It sends the Buddy and Premiere versions, the end of your license key, an anonymous ID for this computer and the last lines of the log. Your Windows user name is removed from file paths.

Buddy folders

Folder Contents
%LOCALAPPDATA%\BuddyEditor\bin FFmpeg.
%LOCALAPPDATA%\BuddyEditor\config License and each module's saved settings.
%LOCALAPPDATA%\BuddyEditor\logs Diagnostics log (buddy.log).
